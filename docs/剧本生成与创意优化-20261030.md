节奏型进模板，节拍进入一致性审计，film/storyboard 流水线新增 `style`/`characters` 输入。

**验证状态**：service 全量单测通过（121s）；流水线契约测试（真 `pipelines.json`）通过；
真机冒烟一次（Ollama dsh-lens-8b，两段共 93.5s，产物 `.tmp/storyboard-live.json`，
六拍结构完整、角色卡具体到疤痕、景别递进合规、finish 用 dissolve 收束）。
**未验证**：真机全链出片（分镜→H3→装配）与新 exe 部署。

## 一、改前诊断：剧本智能为什么"平"

改前整个剧本智能 = `storyboardInstruction`（shotlist.go:21）一份固定系统模板 + **一轮**
LLM 调用，LLM 输出 JSON 后由 `CompileShotPrompt` 机械拼接。六个结构性弱点：

1. **单模板单轮**：无结构层、无迭代；故事结构全靠 LLM 在分镜那一轮顺手发明。
2. **无词表**：模板只口头列举运镜，无受控词表；一致性门只能事后枚举拦截
   （实测 LLM 把 angle 填成景别 → `plan.angle_is_shot_size`）。
3. **无故事结构**：`Shot.Beat` 字段（shotplan.go:48）定义了但**从未生成和消费**；
   没有钩子/铺垫/转折的节奏约束。
4. **角色只有一句话**：`character` 靠模板规则 10 兜底，film 流水线没有角色输入口。
5. **运镜单调**：`plan.camera_monotone` 只是事后 WARN（实测 6 镜 5 镜「固定」），
   生成端没有防单调的机制。
6. **风格全靠裸写**：film 只有一个 prompt textarea，无风格锚；用户不说就没有。

## 三、本次落地（技法 → 代码映射）

| 技法 | 来源 | 落点 |
|---|---|---|
| 级联生成：先结构后镜头 | dramatron / shuohao-skills | `service/storyboard_creative.go`（新文件）：`planShotCreatively` 两段式 |
| 片种卡（按观众期待安排节拍） | xiaoma-director | `storyBeatInstruction` 规则 1：10 个片种 + 期待结构 |
| 冷开场钩子 | shuohao-skills | 结构层规则 2 + 分镜层规则 11 + 审计 `plan.no_cold_open` |
| 角色圣经（可画的定妆描述） | shuohao-skills / huobao-drama | 结构层规则 4 + `characters` 流水线字段（用户输入优先） |
| 节拍表（hook/setup/develop/clash/turn/finish） | dramatron | `BeatPlan.Beats` → 分镜层逐镜携带 `beat` → 审计消费 |
| 节奏型 = 景别序列 | shotlist-forge | `storyboardInstruction` 四个序列（建立/对话/冲突/收束） |
| 受控镜头词表 | shotlist-forge / 自家审计枚举 | 模板词表段（shot_size/angle/camera/light），与审计枚举对齐 |
| 结构层产物供审阅 | Slate（storyboard.json 驱动） | storyboard 节点输出新增 `structure`（BeatPlan JSON） |

**降级策略**（0.x 纪律：不许静默出替代品）：结构层失败（LLM 挂 / JSON 坏）回退单段式——
旧路径仍是完整产品，不是换东西；回退在引擎日志留痕（`[storyboard] 回退单段式`），
节点输出 `structure` 缺席即回退发生。用户点名的 `style` 解析后强制覆盖 plan.Style，
不被模型转述漂掉。

**审计新增（consistency_plan.go §7，全部 WARN 不拦）**：
`plan.beat_missing`（≥4 镜无节拍）/ `plan.beat_monotone`（≥3 镜同一节拍）/
`plan.no_cold_open`（首镜非钩子）。

**流水线字段**（film + storyboard，均 bind `sb-1`，可选项）：
- `style`：画面质感/色调/年代一句话，留空由结构层自拟
- `characters`：每行一个「名字：外貌+衣着+道具」，给出后全片逐镜锁定

## 六、怎么调

- 换结构层/分镜层的创作模型：`data/deps.json` 的 LLM 段或 `OLLAMA_MODEL`。
- 改提示词后必跑：`go test ./service/ -run 'TestPlanShotCreatively|TestStoryboardTemplatesContract|TestAuditPlanConsistency' -count=1`
  （模板契约测试会拦"把词表/节拍改薄"的回归）。
- 真机 A/B 一次提示词改动：`FLOWEDGE_LIVE_LLM=1 go test ./service/ -run TestLiveStoryboardTwoStage -v -timeout 600s`
  （产物落 `.tmp/storyboard-live.json`，人工审阅节拍与词表合规度）。
