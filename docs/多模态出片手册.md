# 多模态出片手册（FlowEdge / MiniMax-H3）

> 这是把 2026-10-19 一整天（含 30 秒成片两轮实战）的经验压缩成的一页决策 + 一页参数 + 一页排错。
> 目标是**下次直接照做**，不再从零试。原始证据在 `AGENTS.md` 与 `.workbuddy/memory/`。

---

## 一、先选路：这笔活该走哪条链路

| 你要的东西 | 走哪条 | 关键点 |
|---|---|---|
| 有人物说台词、口型要对 | **ref2va + 参考音频**（`h3_r2v`） | 只有它暴露 `ref_audios`；`fully_copy` 让音频 1:1 透传 |
| 只要氛围/打斗，没人说话 | **fl2va**（`h3` / `h3_i2v`） | 必须填满声音字段 + 口型可见事实，否则模型自己编台词 |
| 角色要在多段/多镜里长得一样 | **ref2va + 定妆图**（`ref_images`） | 身份由图像锁，不靠文字描述 |
| 单镜 ≤15 秒 | 一次生成 | 124 帧 ≈ 5.17s，243 帧 ≈ 10.1s，362 帧 ≈ 15.1s |
| 长于 15 秒 | **分段 + 装配**（`shot-film.py`） | 每段都带同一组参考图 |

**铁律**：T2V 的台词不可控（实测中文会退化成「枉年 赏我鸡肉海鲜」这种伪中文）。
要台词就上 ref2va，别在 T2V 里硬写。

## 二、时长怎么分（不要均分）

**先按内容给，再吸附网格，最后核对总长。** 均分是最省事但最伤节奏的做法。

H3 帧数网格 = `17k+5`：73 / 90 / 107 / 124 / 141 / 158 / 175 / 192 / 209 / 226 / 243 / 260 / 277 / 294 / 311 / 328 / 345 / 362

| 叙事功能 | 建议时长 | 帧数 |
|---|---|---|
| 建立/定场（大远景 + 一个动作） | 6–8s | 158 / 175 / 192 |
| 对话单回合（一句 + 反应） | 6–10s | 158 / 192 / 226 |
| 交锋主体（能量对撞 / 错身 / 环境爆发） | 11–15s | 277 / 294 / 328 / 362 |
| 收招定格（两句台词 + 留白） | 9–11s | 226 / 243 / 260 |

总时长核对：`sum(frames)/24 − 0.2×(段数−1)`。差超过 0.75s 会告警。

**30 秒三段的实测分配**（优于均分 3×243）：
建立 192（8.0s）→ 交锋 277（11.54s）→ 收招 260（10.83s）= 29.98s。

> 每段内部再切成 2–3 个镜头（`[Shot 2] At 00:03.500, the camera cuts to …`），
> 段内换机位、声音连续；这才是"一镜一生成"做不到的事。

## 三、提示词：两种结构，别混

### T2V / I2V（三段式，英文）
```
integrated_multimodal_description: [Shot 1] …
overall_soundscape: …
non_diegetic_music: N/A
```

### R2V（六段式，英文）
```
subject_definitions: <Picture 1> 是…；<Audio 1> 是念稿音频
summary: [reference generation + audio reuse] …
retention_analysis: <Picture 1> (appears in [Shot 1]): fully_preserved - …
                    <Audio 1>: fully_copy - is reused 1:1 as the target video's complete final audio track.
detailed_description: [Shot 1] …（替代 integrated_multimodal_description）
overall_soundscape: N/A - the complete final audio track is the copied reference audio.
non_diegetic_music: N/A
```

**四条硬规则**
1. **字段不能空**：空着 `overall_soundscape` / `non_diegetic_music`，模型会自己填（含即兴人声）。
2. **不写否定**：cfg=1 没有负分支，"no dialogue / silent / 不要说话"无效甚至反效果。
   压人声用可见事实：`lips stay closed and still, jaw tight, breath audible through the nose`。
3. **台词用 `<d>`**：`(S1) says <d>[Chinese] 让开。</d>`，单句 ≤10 字，说完写收尾动作。
4. **多镜头用时间戳**：`[Shot 2] At 00:03.500, the camera cuts to …`，不给区间。

## 四、角色一致性：定妆图 > 文字描述

```
flux 出定妆图（正面、干净背景、露出服装与法器）
  → 每段都传 ref_images（≤9 张）
  → 提示词 <Picture N> 指认 + retention_analysis: fully_preserved
```

实测（608×352，三段）：青袍/黑袍、束发玉簪、白骨法杖、红瞳全部守住。
**边界**：锁得住服装·法器·剪影·配色，锁不住高相似度五官——低分辨率下脸没多少像素。
243 帧 + 2 张参考图已用满 24GB（剩 ~0.6GB），想提分辨率只能缩时长或减参考图。

## 五、声音：自己做，别指望模型

| 场景 | 做法 |
|---|---|
| 有台词 | TTS（Kokoro）逐句合成 → 按帧数对齐 → `fully_copy` 透传 |
| 要环境声 | 混进同一条 wav（`dub-track.py --ambience`），因为 fully_copy 是全音轨 |
| 只想压住乱语 | 中置相消 `pan=stereo\|c0=c0-c1\|c1=c1-c0`（人声居中、环境声宽） |
| 验收 | ASR 必须能转出剧本原话；无人声镜头必须转不出字 |

**参数**：`turbo` 默认 **12 步**（官方：台词与音色需 12+ 步，8 步音频是短板）；
sigma shift turbo 为 video 12 / **audio 6**，base 为 12 / 3。

## 七、交付前必须过的验收

```bash
python scripts/verify-media.py 成片.mp4 --asr [--expect "原话"] [--no-speech] --gate
```

| 检查 | 抓什么 |
|---|---|
| 流 + 时长 + **精确帧数** | xfade 短于一帧会整段丢画面，时长看不出来 |
| 有效帧率 ≈ 标称 | 同上，帧数比时长诚实 |
| 音画时长差 >0.2s | 拼接丢段 |
| 中段静音 >0.45s | 接缝断音 |
| 响度（max/mean） | 削波 / 近乎无声 |
| ASR | 台词是否念对 / 是否冒出人声 |

退出码 0/1/2；`--gate` 只有 FAIL 才拦。**FAIL 一律不交付。**

## 八、失败模式速查

| 症状 | 根因 | 修法 |
|---|---|---|
| 角色说含糊假台词 | 步数 8 / 缺 sigma 节点 / 声音字段空 / 用了否定式 | 12 步 + 12/6 + 三段式 + 口型事实 |
| 换段就换脸 | 只靠文字描述角色 | 定妆图 + ref_images 每段都传 |
| 接缝闪一下 | 硬拼 | xfade 0.2 + acrossfade 0.2 |
| 某段没声音 | 该段音频几乎是静音 | 逐段测响度（< -42dB 重生成） |
| 时长对但没画面 | xfade d < 一帧 | d ≥ 0.08，offset 留一帧 |
| 念稿变伪中文 | 参考音频没标 `fully_copy` | retention_analysis 明确写 |
| 台词与镜头错位 | wav 里台词位置没对齐切点 | `dub-track --lead` 对齐 |
| 报「3s 内未就绪」 | 依赖启动等待写死 3s | 已改为按类型（H3 180s） |
