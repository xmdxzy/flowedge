# 响度目标：短视频平台以 -14 LUFS 为基准

**规则**：成片整体响度要归一到平台基准附近（约 -14 LUFS）。偏离会被平台二次压限，人声忽大忽小。

**为什么**：平台会对超响的片子做自动压缩，压缩量不受你控制。片子自己先归一，发布后的听感才稳定。

**注意**：-14 LUFS 是行业惯例值，不是 FlowEdge 实测出来的物理常数。具体平台可能有差异，以实测回听为准。

**验证**：`python scripts/verify-media.py 成片.mp4` 看响度段是否在容差内；或 `ffmpeg -i out.mp4 -af loudnorm=print_format=json -f null -` 读 measured_I。
