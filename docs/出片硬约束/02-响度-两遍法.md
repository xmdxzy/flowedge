# 响度归一必须两遍：先测再应用

**规则**：一遍法（直接挂 loudnorm 动态模式）会改变动态、且结果不可预测。必须两遍：
1. 第一遍 `-vn` 只测：`ffmpeg -i in.mp4 -af loudnorm=I=-14:TP=-1.5:LRA=11:print_format=json -f null -`
2. 解析出 `measured_I / measured_TP / measured_LRA / measured_thresh / offset`
3. 第二遍把这些作为 `measured_*` + `linear=true` 喂回去，末尾挂 `alimiter` 防削波

**为什么**：线性模式保动态、结果可复算；动态模式是"边跑边调"，同一片跑两次结果可能不同。

**实现位置**：`backend/service/loudness.go`。

**禁止**：解析失败时把 0 当成实测值 —— 那会让第二遍把整条音频压成静音。解析失败必须 `Valid=false` 退回动态模式，并在产物里标明降级。
