## 一、FlowEdge（FE）是什么（决定「什么知识有用」）

- **形态**：Windows 单机、24GB 显存（RTX 4090 级）的**本地多模态出片平台**。后端 Go 单文件 exe + React 前端。
  唯一运行入口 `POST /api/produce {pipeline, params, invoked_by}`。
- **7 条固定流水线**（`data/pipelines.json`）：`image` / `image_batch` / `image_edit` / `video` /
  `video_from_image` / `film` / `voice`；另有 `knowledge_film`（代码视频）。用户选一条、填字段即出片。
- **13 种节点**（唯一元数据表 `backend/service/nodespec.go`）。加节点要改两处：`nodespec.go` + `nodecatalog.go`。
- **已有能力**：
  - 本地 **MiniMax H3** 音视频联合生成（`text2video` / `ref2va` 六段式）；生产已用 W4A8 量化权重；
    台词镜走 `h3_r2v`，非台词 FL2VA 走 PDD 8 步 LoRA。默认灰度：608×352×124 帧 @12 步。
  - Flux 文生图 / MOSS（图内有字优先）；Ollama LLM（分镜、提示词优化）；
    **Kokoro**（CPU，RTF 0.33–0.95）+ **edge-tts**（`zh-CN-XiaoxiaoNeural`）做配音；faster-whisper ASR。
  - **代码视频链**：`code_video` 节点 + `knowledge_film` 流水线 = lemo-opuscar 的 headless 渲染
    （Playwright 逐帧截图 → ffmpeg），模板在 `backend/service/codetpl/<style>/`（go:embed）。
    **走 CPU 道**，与 GPU 生成并行不抢显存——这是混合出片的效率支点。
    > **2026-10-31 实测更正**（原简报此处过期，已核实源码）：`codeVideoStyles` **已有 4 种**
    > （`blueprint` / `darkcard` / `atlas` / `studio`），`knowledge_film` 的 `style` 默认值已是 **`darkcard`**。
    > 加新风格要改 **4 处**：`codetpl/<style>/{index.html,render.js}` + `code_video.go` 的 `codeVideoStyles`
    > **和** `codeVideoStyleNames`（漏后者则 live 冒烟不覆盖）+ `pipelines.json` 的 `style.options`。
  - 质量门控：`quality_loop` 壳 + `quality_gate.go`；验收脚本
    `python scripts/verify-media.py <mp4> --asr --frames <dir>`（流列表/精确帧数/音画差/静音缺口/响度/ASR），
    返回 FAIL 不许交付。
- **已锁定决策（不可推翻，子智能体不许建议推翻）**：
  1. **知识类 / 科普类 / 产品介绍片不加 BGM**（用户 2026-10-30 拍板）——人声清晰度优先。
     需要氛围只用极低电平环境声（`mixRoomTone`，−36dBFS brown noise）。
  2. 响度只在**剪辑层归一一次**（别在多个环节各压一遍）。
  3. 字幕排轴必须用**实测时间戳**（TTS 每句自带前导静音，按计划值排轴必漂）。
  4. 权重只放 `D:/AI/Models`，不存项目目录。
- **已知自有缺口**（2026-10-31 更正）：
  - ~~只有工程蓝图一种视觉~~ → **已 4 种风格，默认 darkcard**；真正缺口是「风格有壳、缺质检与字体纪律」：
    `codetpl/shared/kit.js` 用系统字体栈，违反 lemo 官方「CJK 子集化 + 自托管」要求（跨机版式不确定、缺字静默回退）。
  - 多镜一致性只有**文字锁**，`Shot.Transition=continue` 只是标签、**无像素级锚**（上一镜末帧不回填下一镜）。
  - `verify-media.py` 不查「cut 用了 <1 帧淡化导致整段画面丢失」这类事故（时长与音频全对，无工具能发现）。
  - `data/comfy_workflows/` 不存在，但 `backend/service/multimodal.go` 的 `ComfyTemplateDir` 指着它（悬空引用）。

## 三、可用工具（已实测可用）

- **`agent-reach`**：`agent-reach <渠道> <动作> [参数]`，默认输出一行 JSON；`ok:false` 看 `error.code`。
  | 渠道 | 状态（2026-10-31 实测） | 可用动作 |
  |---|---|---|
  | `youtube` | **PASS 3/3，无需登录** | read / search / subtitle / transcribe |
  | `bilibili` | search/read/hot PASS；**subtitle 需登录** | search / read / hot |
  | `github` | 默认渠道 | search / read |
  | `web` | 默认渠道 | search / read |
  | `xiaohongshu` | optional，安装中 | search / read / comments（**需用户本人登录**） |
  | 抖音 | **无渠道** | 只能走公开 web / 第三方拆解文 |
  使用前先 `agent-reach channels` 看动作与参数。**红线：只读，不代登、不索要密码。**
- **arXiv MCP**：`mcp__arxiv__search_papers` / `get_abstract` / `download_paper` / `read_paper` /
  `search_paper_text` / `semantic_search`。
- **HuggingFace**（无专用渠道，用 `web_fetch` 直打 API）：
  - 模型列表：`https://huggingface.co/api/models?search=<kw>&sort=downloads&limit=30`
  - Space 列表：`https://huggingface.co/api/spaces?search=<kw>&sort=likes`
  - 论文：`https://huggingface.co/papers`、`https://huggingface.co/papers?q=<kw>`
  - 单个模型卡：`https://huggingface.co/<repo>/raw/main/README.md`
- `web_search` / `read_page` / `ops_grep` / `ops_read_files` / `write` / `edit`。
- ⚠️ 本机 shell 有 `http_proxy=http://127.0.0.1:5751`，探测本地端口一律 `curl --noproxy '*'`。

## 四、交付规范（强制，违反视为返工）

1. **只写文档**。不要改任何代码、不要跑出片管线、不要动 ComfyUI/引擎（那是主会话的活）。
2. **交付路径**：`docs/视频知识库/<你的编号>-<主题>.md`（编号由父会话在任务块里指定）。
3. **章节结构**（照此写，缺节视为不完整）：
   - ① **一句话结论**
   - ② **主体**（**表格优先**，别写散文）
   - ③ **与 FE 的对接点**——明确「接到哪条流水线 / 哪个节点 / 要改哪个文件 / 缺什么依赖」
   - ④ **可复现动作**——有具体命令 / 参数 / 仓库路径 / 模型 id
   - ⑤ **没验证的部分**——单独一节，**不许省、不许含糊**
   - ⑥ **来源清单**——markdown 链接
4. **证据纪律**：
   - 每个数字/结论**都要标来源**；区分「一手实测」与「二手整理 / 作者自述」。
   - 拿不到就写「未取到」，**禁止编造**（星数、播放量、参数、版本号一律不许猜）。
   - 「标准 / 最佳实践」按序取证：**本地源码与官方范例 → 官方仓库原文 → 官方文档页 → 社区博客（只当索引）**。
     指不到原文的那一条就是猜测，必须标注为猜测。
5. **产出体量 ≤ 40KB**，表格优先。中文写作。
6. **完成后只用一句话回报父会话**：`文件路径 + 核心结论`（正文留在文件里，不要贴回）。
