> 所有数字都是本机 RTX 3090 实测，推断项单独标了「未验证」。

| 资产 | 位置 | 说明 |

| 音色 `my-voice` | `运行/local-services/voices-breeze/my-voice/` | 参考 = `ref-12s-enh-nc.wav`（高通+降噪，未压缩） |

## 2. 用法

```bash
python scripts/douyin-voice.py --text "文案…" --out out/koubo.wav
python scripts/douyin-voice.py --text-file 文案.txt --plain   # 不加口播风格，纯克隆
```

脚本内固定：`instruction="语速稍快，声音明亮清晰，有亲和力，带自然的语气起伏和重音"`。

## 3. 实测规格（8.80s / 45 字样本）

| 项 | 值 | 判据 |
|---|---|---|
| 采样率 | 48000 Hz 单声道 | 视频工程通用 |
| 响度 | -15.7 LUFS | 平台会归一化到 ~-14 |
| 真峰值 | -1.5 dBTP | 上限 -1.0 |
| LRA | 1.2–2.2 | 低于 1.0 会显"念稿机器" |
| 语速 | 5.11 字/秒 | 抖音口播 5–6 |
| 合成耗时 | 热态 RTF 0.6–1.4 | 8.8s 音频约 10s |
| 显存 | 峰值 22.8GB / torch 自认 8.4GB | 差额是 CUDA Graph 静态缓存 |

## 4. 三条硬约束（都是撞出来的，不是配置问题）

### 4.1 参考音频必须 ≤12 秒
20.6s 参考音频会报：
```
RuntimeError: backbone prefill CUDA graph (1, 352) was not declared in the warmup profile
```
`D:\AI\breeze-tts\configs\fast.json` 第 137–233 行：batch=1 的 prefill 只声明到 256，
352 只存在于 batch=2 组。12s ≈ 205 token 落在 224/256 内。

突破方式（未验证）：把该文件 `freeze_after_warmup` 改 false 让运行时现场捕获。
试过一次，因当时显存只剩 11.8GB（门槛 20.3GB）没能重启验证，已回滚。

### 4.2 `cfg_scale` 对克隆无效
```
Template 'ref_clone_tata' does not define a negative prompt but cfg_scale=1.5
```
克隆模板无负面提示词，只接受 1.0。**「调 cfg 找更像」这条路不存在**，
可调的只有 `instruction` / `seed`。

### 4.3 冷启动 193–271 秒
引擎空闲 10 分钟会 `[idle-reclaim]` 回收 TTS 显存（日志实证）。下次首句要付：
进程启动 ~6s + 模型加载与图捕获 193.7s（实测）。热态才是 10s 级。
**出片流程里插 TTS，第一次必然拖 3 分钟以上。**

## 5. 参考音频的硬指标（决定克隆上限）

| 指标 | 本次实测 | 建议 |
|---|---|---|
| 峰值 | -16 dBFS | -6 ~ -3 |
| RMS | -36 dBFS | -20 ~ -26 |
| SNR | ~12 dB | ≥25 dB |
| 底噪 | -44 dB | ≤-55 dB |

本次录音增益偏低，克隆输出 RMS 只有 -31dB（把"轻声"一起学走了）。
后处理（`enhance-ref-voice.py`）能把 SNR 从 11.9 → 26.2dB，
**但增益低这件事只能靠重录解决**，增强只是减分后的补救。

## 6. 未验证 / 已知取舍

- **音色主观评价**：MFCC 余弦 0.989 只是频谱包络口径，用户口头确认「挺像的」，
  但没有多说话人盲测。
- **`seed` 非严格确定**：同 seed=42 两次合成得到 4.00s / 4.40s，说明 CUDA Graph
  路径下并非逐比特可复现。
- **压缩会破坏音色**：带 `acompressor`/自实现压缩的参考增强，MFCC 从 0.992 掉到 0.959，
  已排除；`--no-compress` 才是推荐档。
- **-14 LUFS 达不到**：内容峰均比 ~14dB 时，TP=-1.5 约束下 loudnorm 上限 -15.7；
  强压（acompressor 3.5:1）后仍是 -15.7，说明是 TP 卡死而非压缩不足。
