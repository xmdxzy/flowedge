# MOSS 文生图后端接入验收

> 结论先说：**MOSS 是 FlowEdge 第二个文生图后端，专治 flux 画不出字的问题**——
> 图内中英文文字、bbox 布局控制均实测可用；引擎 `backend=auto` 按提示词自动选路已落地。
> 本目录只收验收截图，判据与方法见 `docs/多模态出片手册.md` 与 `docs/AGENTS-实现档案.md`。

## 背景：为什么要有第二个后端

| | flux（schnell-fp8） | MOSS |
|---|---|---|
| 步数 / 实测耗时 | 4 步 ≈ 3s | 50 步 ≈ 52s |
| 峰值显存 | — | ≈ 15.5GB |
| 图内文字 | **画不出**（4 步蒸馏，字形必烂） | 中英文均可，书法字形正确 |
| 布局控制 | 无 | bbox 布局注入（0–1000 归一化 `[y0,x0,y1,x1]`） |
| 端口 | ComfyUI 主实例 :8188 | 独立实例 :8190 |

选路逻辑在 `backend/service/t2i_backend.go`：`backend=auto` 按提示词文字信号与
layout 参数自动二选一，reason 写进节点输出；`flux` / `moss` 也可显式指定。

## 复现要点

- 权重迁移三处 `extra_model_paths.yaml`（主实例 / H3 / MOSS）各自 `/object_info` 验。
- MOSS 复用 H3 的 venv（torch 2.14），与主实例显存**单侧驻留**，不同时占。
- 探测一律 `curl --noproxy '*'`。
